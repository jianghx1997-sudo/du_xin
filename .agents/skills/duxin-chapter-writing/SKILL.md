# 语音稿优化

保留原技能目录供兼容，职责已改为语音稿轻修。遵守项目根目录 `AGENTS.md`。

- 先读取作者原稿；需要核对名字、承接或作者改动时，读取相关最新本地正文。
- 超过二十字的完整句子一般可以另起一段，结合语境，不截断完整意思，不把对话拆碎。
- 只纠正有依据的同音人名、明显错字、标点、语病；残缺句补到能读通即可。
- 正常句子尽量不动。重复信息、原有对话、动作、心理和段落顺序均保留。
- 不删句、不重排、不统一成模板文风，不擅自补剧情、情绪、动作或对话。
- 意思不明或存在超出轻修范围的逻辑问题，附简短提示，不替作者决定。
- 作者明确要求补充专业知识时，先核验，再在相关位置少量补充，不借机扩写其他地方。
- 交付前对照原稿检查遗漏、误删、误改和人名一致性，不启动独立编辑或复审门禁。
- 默认在对话中给完整修改稿，不另写下一章、不自动存档；作者要求修改本地文件时，只处理指定范围。
