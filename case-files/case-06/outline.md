# 案件六：春山小馆危化品伤人案

## 基本信息
- **章节范围**：第80-103章（文件 081-104）
- **案件类型**：现行犯 / 蓄意伤害（未遂）
- **受害人**：叶晴（春山小馆女店员）
- **嫌疑人**：灰衣男人（叶晴通过网络群认识的纠缠者）
- **动机**：叶晴与他吃过两次饭后拒绝交往、交了新男友，他认为叶晴"背叛"他，决定用强碱清洗剂毁她的脸

## 案件推进

### 案发
1. 时菱休假去春山小馆吃饭，排队时通过读心发现前面灰衣男人异常
2. 男人心声暴露：目标是店门口女店员叶晴，包里有腐蚀性液体（强碱清洗剂）
3. 时菱战斗力不行，正发愁时顾晏廷到达（他看了时菱的朋友圈，开车五公里来"偶遇"）
4. 时菱用手机备忘录传递信息给顾晏廷
5. 顾晏廷在男人拧开瓶盖的瞬间出手，一扣腕把他压在墙上
6. 时菱控制现场，让围观群众后退，报警

### 后续发酵
1. 视频上热搜，标题从"便衣警察制服袭击者"→"先发现危险的漂亮小姐姐"
2. 多角度视频被扒出，证实是时菱先发现异常、用手机提醒顾晏廷
3. 时菱的大学同学、高中同学纷纷来问
4. MCN公司打电话想签时菱做网红
5. 大学室友林韵想挖她去企业
6. **时菱全部拒绝**

### 市局反应
1. 郑局长人在省里培训，看到战力榜江城排第二，打电话问王局
2. 回来后发现各方都在打听/挖时菱（省厅领导、外地同行、MCN公司）
3. **郑局长亲自请时菱留下来**，姿态放得很低
4. 第二天班子会全票通过，时菱身份正式落地
5. 三队庆祝，陈继东激动拍墙

## 感情线推进（本案承载量大）
1. 顾晏廷加时菱微信——斟酌半天只发了名字
2. 顾晏廷看时菱朋友圈后开车五公里去"偶遇"
3. 两人在面馆吃饭，顾晏廷提出带她训练防身术
4. **时菱发现听不到顾晏廷心声**（第一次确认能力有盲区）
5. 三队八卦两人为什么同时出现在春山小馆
6. 顾母在视频里看到儿子和时菱，追问"那个女孩子是谁"
7. 顾晏廷对母亲说"心里有数"——第一次松口

## 原生家庭线
1. 时薇和沈美玲在热搜上看到时菱和顾晏廷同框
2. 沈美玲确认便衣警察就是顾晏廷（时家原本想让时薇去搭讪的人）
3. 时薇冲到市局想找时菱算账，被刘航元和张海涛挡在楼下
4. 时菱下来后冷淡应对——"我已经离开时家了，没有跟你汇报的义务"
5. 叶晴正好来送锦旗，时菱丢下时薇去接待叶晴——对比强烈

## 案件收尾
- 叶晴到市局送锦旗（一面给时菱、一面给顾晏廷）
- 叶晴讲述被纠缠的完整经过——"他觉得我跟他吃过两次饭就是答应他了"
- 叶晴决定离开江城，去母亲所在的城市重新开始

## 系统结算
- S级任务评级
- 新奖励发放

## 人物成长
- 时菱：身份从"特邀顾问"变为正式人员
- 时菱意识到自己的体能短板，决心跟顾晏廷训练
- 顾晏廷：从"不打算谈恋爱"到"心里有数"
- 沈睿：正式服气——"服了就是服了，麻木了也是真的麻木了"
- 刘航元：从最初看不起时菱到害怕她离开
- 郑局长：从"要亲自看看"到"亲自请她留下"

## 写作参考
- 这是全书**感情线和主线融合最密集的案件**——案件本身简单（现行犯当场制服），但后续发酵包含了感情线、职场线、家庭线、社会舆论线
- 春山小馆和商场拐卖案的"休假偶遇案"形成呼应
- 时菱拒绝MCN的理由是重要的价值观表达
- 顾晏廷"五公里偶遇"是感情线关键节点——注意克制，不能让他显得太主动
- 时薇来闹的段落要写得有对比：时菱被团队保护vs时薇孤立无援
