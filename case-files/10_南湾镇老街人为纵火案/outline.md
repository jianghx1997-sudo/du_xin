# 案件十：南湾镇老街人为纵火案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

> 本案原为陆承安旧案中途插入的现案，现已单独拆分为独立案件目录。

## 基本信息

- **章节范围**：第159章至第166章（文件 160-167）
- **案件类型**：人为纵火致人死亡、重大公共安全案件、现案攻坚
- **地点**：南州城南南湾镇老街
- **伤亡结果**：三人死亡、六人受伤，死者包括一名八岁儿童
- **真凶**：周立军
- **核心动机**：周立军曾在起火楼栋租住，并在附近摆摊，因楼道堆放杂物、欠租、摊位占道和死者家庭、房东、小卖部老板多次发生矛盾。他认为对方害他没了住处、摆不了摊，于是放火报复。
- **本案一句话卖点**：全省关注的重大纵火案里，时菱没有案卷可翻，只能在火场外守一天，等凶手自己回来看热闹。

## 案件背景

1. 南湾镇老街为老旧自建楼和沿街出租房混杂区域，楼道窄、杂物多、监控稀少。
2. 火灾最初由消防处置，后因一楼楼梯间、二楼平台和后门附近有异常燃烧痕迹，转为故意纵火侦办。
3. 现场有汽油味和流淌燃烧痕迹，说明不是单点普通起火。
4. 伤亡严重，省公安厅刑侦总队副总队长王力到南州指导，陆承安旧案专班被迫暂停。

## 案件推进

### 第一阶段：旧案被打断

1. 陆承安旧案复核进入僵持阶段时，南湾镇老街火灾突然升级为重大人为纵火案。
2. 邵立民要求能抽调的人全部投入现案，积案攻坚暂时放一放。
3. 时菱没有正式参与专案的明确位置，于是主动思考自己还能做什么。

### 第二阶段：寻找非常规入口

1. 时菱向沈睿请教纵火案常见类型、动机和嫌疑人事后行为。
2. 沈睿提到部分纵火者可能重返现场，观察火灾结果或围观警方调查。
3. 时菱和顾晏廷决定去火场外围观察，但不进入封控现场，不干扰主办单位办案。
4. 两人在外围从上午守到傍晚，过程漫长且不确定。

### 第三阶段：发现周立军

1. 时菱在人群中听到周立军心声，判断他在观察警方进展，并确信自己不容易被查到。
2. 她没有立刻行动，先等顾晏廷靠近，确认现场可控。
3. 时菱喊“站住”试探，周立军转身要跑。
4. 顾晏廷将人控制，南州警方把他带回。

### 第四阶段：南州补证定案

1. 南州专案组没有直接凭时菱判断定案，而是围绕周立军展开走访、身份核验、监控比对和依法搜查。
2. 周立军最初报假名，后被查出三个月前曾在起火楼栋租住。
3. 走访发现他与死者家庭、房东、小卖部老板存在租住、摆摊、占道和杂物堆放矛盾。
4. 监控组通过步态特征将周立军与案发前拎桶经过老街巷口的人影联系起来。
5. 搜查周立军住处时，发现一双被刻意刷洗过的鞋，鞋底纹路中卡有变形蓝色塑料碎片。
6. 火场靠墙位置也有被烧变形的蓝色塑料碎片，颜色、厚度、弧度与鞋底碎片高度接近。
7. 鞋底火场残留物与现场残留物比对后，周立军心理防线崩溃并交代。

## 证据链

1. 火场异常燃烧痕迹、汽油味和多处燃烧点，证明人为纵火方向。
2. 监控中拎桶人影和周立军步态特征吻合，形成侦查指向。
3. 周立军报假名、曾租住起火楼栋、与死者家庭及周边人员有矛盾，补强动机和机会。
4. 刷洗过的鞋、鞋底蓝色塑料碎片和火场蓝色塑料残留高度对应。
5. 鞋底火场残留物与现场残留物比对结果，成为压垮周立军的关键证据。
6. 周立军供述与走访、监控、搜查结果互相印证。

## 时菱发挥点

- 主动补纵火案知识，找到“重返现场”这一观察方向。
- 在封控现场外守候，没有越权进入现场或指挥南州警方。
- 通过心声捕捉和“站住”试探锁定嫌疑人，再交由南州警方依法补证。

## 本案作用

1. 打断陆承安旧案，制造现实办案资源冲突。
2. 让时菱和顾晏廷在南州、省厅人员面前建立可信度。
3. 为陆承安旧案后续“女主坚持不被看好的方向”铺垫情绪。
4. 与陆承安旧案合并触发系统结算。

## 后续可回收点

1. 王力、省厅罗建平等人对时菱留下深刻印象，是 N 省感谢函和外地公安关注时菱的前置原因。
2. 本案破局方式是“现场外围观察重返现场人员”，后续新案应避免短期重复。
3. 周立军只作为本案凶手，不需要后续再展开。
