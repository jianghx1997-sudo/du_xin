# 案件三：跨省儿童拐卖案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

## 基本信息

- **章节范围**：第40章至第53章（文件 039-053）
- **案件类型**：跨省儿童拐卖团伙案、商场拐带、中转窝点
- **受害者**：多名被拐儿童
- **主犯**：马会琴，“琴心母婴生活馆”店主
- **重要成员**：老孙、抱孩子女人、看孩子女人等
- **核心动机**：通过拐卖儿童牟利，利用母婴店和临时窝点做掩护，进行接应、中转和转卖。
- **本案一句话卖点**：时菱休假买冰淇淋时撞见“假家长”，一通电话把即将被转走的孩子抢了回来。

## 案件推进

### 第一阶段：跨省协查

1. 临川公安向江城申请协查，确认拐卖团伙可能进入江城。
2. 江城市局围绕商圈、交通线、车站和可疑人员全面铺开。
3. 案件压力很大，至少还有孩子掌握在团伙手里。

### 第二阶段：商场发现异常

1. 时菱休假时在新茂商场发现两名可疑女人，其中一人抱着孩子。
2. 她听到对方心声中出现“B2”“老孙”“换衣服”“上车”“马会琴”等关键词。
3. 时菱没有惊动对方，立刻联系陈继东，提供位置、动向和风险判断。
4. 警方一边保护孩子，一边盯住东门和 B2 两条线。

### 第三阶段：救孩子和端窝点

1. B2 停车场中，老孙准备接孩子，江明等人当场控制接应人员。
2. 东门线继续追踪，顺藤摸到临时中转窝点。
3. 窝点中救出多名孩子，现场发现奶瓶、药片、一次性手机卡、假证和转运记录。
4. 沈睿等人发现孩子被喂药，进一步确认案件恶劣程度。

### 第四阶段：锁定马会琴

1. 时菱通过看孩子女人的心声和反应，判断真正负责人是本地女性，店面和孩子、女性、家庭用品相关。
2. 警方锁定“琴心母婴生活馆”，找到马会琴。
3. 时菱在问讯中通过反应判断，马会琴三年前还卖过孩子，方向指向临州。
4. 刘航元等技术人员恢复手机和通联记录，临州协查线展开。

## 证据链

1. 商场可疑人员的动线、分头逃离和 B2 接应车，证明现场不是普通家长带孩子。
2. 老孙、抱孩子女人和窝点看守互相印证，构成前端转运链。
3. 窝点中的药物、奶瓶、假证、转运记录和一次性手机卡，证明团伙化运作。
4. 琴心母婴生活馆的地理位置、后巷通车条件、涉案人员反应，指向马会琴。
5. 马会琴旧手机和通联记录，牵出三年前临州旧线。

## 时菱发挥点

- 用“真正家长会把注意力放在孩子身上”的行为基线识别假家长。
- 在商场现场克制处理，不打草惊蛇，先保孩子，再保线索。
- 审讯看守女人和马会琴时，通过反应和心声判断组织结构、店面类型和旧案方向。

## 人物变化

- **时菱**：第一次在休假状态下撞见重大案件，救回多个孩子，价值感大幅增强。
- **三队和二队**：在跨省协作里形成更强配合。
- **沈睿**：参与现场救助和后续调查，对时菱判断有更直观认识。
- **王局**：明确意识到必须留下时菱。
