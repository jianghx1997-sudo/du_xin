# 案件五：清河遇害案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

## 基本信息

- **章节范围**：第70章至第79章（文件 071-080）
- **案件类型**：农村命案、熟人社会、第一现场误判
- **受害者**：林小禾，青石村村民
- **真凶**：李国顺，村里口碑很好的养殖大户
- **核心动机**：林小禾发现李国顺违规处理病死猪，试图拍摄举报。李国顺抢手机时导致她撞到后棚门槛受伤，随后继续实施致死行为，并转移尸体、清洗现场。
- **本案一句话卖点**：清河县查了十来天都被熟人滤镜困住，时菱换了一个问题，直接找到了被漏掉的小路和“好人”背后的后棚。

## 案件推进

### 第一阶段：清河县求援

1. 清河县已围绕林小禾社会关系查了十来天，重点怀疑过周大河、马三狗、王宝成。
2. 当地路网复杂、监控少、案发后下雨，脚印车辙基本被毁。
3. 熟人社会里每个人都知道一点，却又夹杂着闲言碎语和个人偏见，调查越听越乱。

### 第二阶段：换问题框架

1. 时菱没有先问谁最像凶手，而是问“林小禾那晚为什么往村后去”。
2. 死者家属和现场走访显示，林小禾出门前换过适合走泥路的鞋。
3. 清河县原路线图重点在主路，忽略了屋后通往村后的多条小路。
4. 顺着小路往前，能到李国顺养殖场后方。

### 第三阶段：李国顺露出异常

1. 李国顺在村里口碑很好，热情配合，连本地警察都本能替他说话。
2. 时菱靠近李国顺后，听到他最怕警方往后棚走。
3. 她没有当场点破，而是观察后棚、白色皮卡和李国顺对问题的回避。
4. 陈继东选择相信时菱，直接将李国顺带回。

### 第四阶段：后棚门口定案

1. 刘航元查到白色皮卡案发当晚有两趟异常，回来时后斗压得更低。
2. 江明和现场人员在后棚门口门槛、排水沟和可冲洗区域重点排查。
3. 后棚门口发现林小禾血迹、带毛囊头发和衣物纤维。
4. 李国顺在审讯中从否认见过林小禾，改口到承认她到过后棚门口，最终崩溃。

## 证据链

1. 林小禾换鞋和屋后小路，证明她当晚有明确目的，不是随机走到发现地。
2. 小路连接李国顺养殖场后方，打通死者真实动线。
3. 李国顺对白色皮卡、后棚和林小禾到访的说法前后矛盾。
4. 白色皮卡监控显示案发当晚异常往返，后斗重量变化异常。
5. 后棚门口血迹、头发和衣物纤维与林小禾对应，证明第一现场。

## 时菱发挥点

- 改变提问框架，从“谁杀了她”转为“她为什么走到那里”。
- 破除“李国顺是村里好人”的滤镜。
- 通过心声和外部反应把重点压到后棚门口，再由警方补强客观物证。

## 人物变化

- **时菱**：能力升级后第一次在顾晏廷面前完整参与命案侦破。
- **顾晏廷**：首次亲眼见证时菱判断如何推动案件，负责审讯和现场安全。
- **陈继东**：对时菱的信任进一步加深。
- **清河县副队长**：从怀疑到道歉感谢，可后续作为外地协查方回归。
