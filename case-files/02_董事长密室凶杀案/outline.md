# 案件二：董事长密室凶杀案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

> 本案纲按当前本地最终稿整理，重点同步何清线和密室真相。

## 基本信息

- **章节范围**：第20章至第38章（文件 020-037）
- **案件类型**：暴雨夜富豪命案、伪密室、旧怨复仇
- **受害者**：刘明辉，明辉集团董事长
- **真凶**：何清，刘明辉身边工作七年的行政助理
- **核心动机**：何清的姐姐何岚当年被卷进刘明辉早年的旧业务，被一步步推到最前面承担责任，最后又在雨夜争执中被刘明辉推下河堤，案卷以“意外死亡”收尾。何清多年收集材料，最终决定复仇。
- **本案一句话卖点**：所有人都被“密室”框住，时菱先拆掉前提，再从背景板里拎出真正藏了七年的复仇者。

## 案件推进

### 第一阶段：密室前提

1. 刘明辉死在私人别墅一楼书房，死因是锐器割裂颈部导致大出血。
2. 凶器是书桌上常年摆放的大马士革裁纸刀。
3. 案发当晚下大雨，外围监控受影响，书房门窗看似从内部反锁。
4. 明面嫌疑人包括现任妻子苏琳、长子刘泽、集团副总王建等人，均有利益或矛盾。

### 第二阶段：时菱拆掉“密室”

1. 时菱没有顺着“凶手如何从密室离开”往下想，而是提出门锁前提未必可靠。
2. 江明等人复查锁具，确认书房老式门锁可以用钥匙从外面上双圈。
3. 案件从“内部反锁的密室”变成“熟悉书房、钥匙和动线的人伪造反锁”。
4. 沈睿和二队最初不服，但锁具事实让所有人不得不重新调整方向。

### 第三阶段：何清浮出水面

1. 时菱要求重新筛当晚在别墅活动、接触书房和档案柜的人。
2. 何清从背景人物里被单独圈出。她能进书房，熟悉钥匙，知道刘明辉作息，又长期负责核心文件和日程。
3. 刘航元等人查出何清姐姐何岚曾与刘明辉早年旧业务有关，后来“意外死亡”。
4. 何清主动承认杀害刘明辉，并说明自己多年收集材料、等待机会。

### 第四阶段：作案真相

1. 何清真正决定动手，是因为刘明辉几个月前认出她的身份，开始试探她。
2. 她选择案发当晚，是因为那天大雨遮挡监控、佣人和司机都不愿频繁走动，屋内人也容易各自回房。
3. 刘明辉当晚情绪很差，几个人轮流进书房后，火气不断堆高。
4. 何清拿着需要放回档案柜的材料进入书房。刘明辉没有防备她。
5. 她趁刘明辉转身找东西，拿起桌上的裁纸刀动手；随后简单归回书房物品，处理自己触碰过的裁纸刀位置。
6. 她用提前刻好的备用钥匙从外面锁上书房，再借混乱去二楼盥洗室处理手上和外套上的血迹。
7. 她同时安排旧事材料上热搜，不想让刘明辉死后继续保留“好人”名声。

## 证据链

1. 锁具复查：证明书房可以从外部上双圈，不是真密室。
2. 何清动线：案发当晚她有进出书房和处理痕迹的条件。
3. 旧案材料：何岚死亡、旧业务责任转嫁和刘明辉之间形成明确动机链。
4. 何清口供：作案顺序、锁具使用、盥洗室处理痕迹与现场补查吻合。
5. 外套血迹：袖口和下摆内侧检出刘明辉血迹，喷溅方向与书房站位对应。

## 时菱发挥点

- 先质疑“密室”这个前提，避免所有人被错误框架带偏。
- 从明面嫌疑人之外重开范围，抓住何清这个被默认忽略的助理。
- 通过行为反应和心声判断何清不是普通工作人员，而是与刘明辉有更深旧怨。

## 人物变化

- **时菱**：完成第二个大案，证明自己不只靠直觉，还能抓住推理前提。
- **沈睿**：从专业质疑开始动摇，第一次认真看见时菱能力。
- **赵刚和二队**：从不服到承认她抓住了关键。
- **王局**：正式意识到时菱能带来真实破案效率。

## 写作注意

1. 何清不是临时冲动杀人，她是多年收集材料、逐步准备后的复仇。
2. 何岚线要写成人被旧业务吞掉的悲剧，不要只写成“姐姐死了所以报仇”的单薄动机。
3. 密室核心爽点是“前提被推翻”，不是复杂机关。
4. 后续提及本案时，重点是时菱拆前提、筛背景人物、何清旧怨复仇。
