# 第37章 事情真相

“你到底是从什么时候开始准备这一切的？”

何清坐在灯下，脸色比刚才还要平静。

这个问题她已经在心里回答过无数次，真正说出口时，反而不需要太多力气。

“从我姐姐死后。”何清垂下眼。

“最开始不是为了杀他。最开始，我只是怕那件事真的被埋干净了。”

“姐姐留下来的东西，我一开始只敢偷偷留下来。短信、借条、她那段时间写下来的东西，还有后来我一点点找出来的材料。”

“我怕时间久了，所有人都只记得案卷上那句意外死亡，没人记得她是怎么被逼到那一步的。”

她说到这里，嘴角极轻地动了一下，像是在笑，又像根本不是笑。

“后来我进了刘明辉公司。”她继续道。

“一开始也不是为了动手。我只是想离近一点，想知道当年到底还有多少东西被他压下去了。”

“可我越靠近，就越发现，他根本没变。”

“他还是会把责任往下压，还是会把人推出去顶着，还是会在所有事情过去以后，继续坐在那个位置上讲体面、讲责任、讲自己有多不容易。在外人面前还是一副好人形象。”

提审室里没人出声。

只有记录员的笔在纸上划出很轻的沙沙声。

“所以后来，我收集的就不只是姐姐那件事了。”她说，“他这些年做过的事，甩出去的责任，逼别人的证据，我都开始悄悄留下来。”

沈睿皱着眉，问了一句：“所以你从那个时候开始，就已经在想以后要怎么杀他？”

“不。”何清摇头，“真正决定要杀他，是之后的事。”

句话一出，屋里所有人都更专注了。

“他认出我是谁了。”

赵刚眼神一沉：“什么时候？”

“几个月前。”

何清说，“一开始他只是起疑，后来他也暗自调查，就大概猜到了。”

“他没明说，但他开始试探我，开始故意提起姐姐，开始看我会不会怕。”

“他甚至觉得，这样也没什么。他还是觉得，当年的事已经过去了，死人不会说话，活着的人总得低头。”

“所以你才决定动手？”陈继东问。

“是。”何清点头，“也是从那个时候开始，我不再只准备材料。”

她没有绕弯子，直接把后面她的行动说了出来。

她开始观察刘明辉在家里的作息，观察他什么时候最容易单独留在书房，搞清楚书房那把锁的结构，搞清楚备用钥匙平时在谁手里经过，观察盥洗室和走廊之间哪一段最不容易被人撞见。

“我在他身边待了七年。”她说，“很多人不知道的东西，我都知道。”

“书房那把锁怎么从外面上双圈，备用钥匙能碰到哪里，什么时候别人都不敢进书房，什么时候只有我进去不会显得突兀。”

赵刚继续问：“案发当天，你再说一遍。”

何清没有抗拒。

最先让她决定动手的，是那场大雨。

江城那天傍晚开始变天，入夜以后雨越下越大，雷声一阵接着一阵。

别墅外面的部分监控受天气影响，画面断续不稳，院子里和外墙那几处原本容易被拍到的角度，也被雨幕糊得不清楚。

那样的天气，佣人不会频繁往外走，司机也大多留在车库和廊下，屋里的人只会更急着回到自己的房间。

她知道，这种机会不会常有。

那天晚上，刘明辉情绪本来就不好。

几个人轮流进了他的书房，刘明辉的火气一层一层往上堆。

等到最后一个人从书房出来的时候，何清知道自己机会来了。

她进去时，手里还拿着一份需要放回档案柜的材料。

刘明辉没有防备她。

何清就在那一刻动了手。

她没有提前带凶器，书桌上那把裁纸刀，平常就放在那里。

她趁刘明辉转身去找东西的时候，伸手拿到了那把裁纸刀。

那一下正好对应尸检里最关键的颈部伤口。

刘明辉倒下后，她先听了一会儿门外的动静。

走廊没人。

她把书房里被碰乱的地方简单归回原样，把自己拿进去的那份材料放到该放的位置，又处理了裁纸刀上自己碰过的位置。

她早就提前去刻过备用钥匙。

简单收拾了现场，她立刻锁门出来，然后趁楼下乱成一团，去了二楼尽头的盥洗室。

她把手上和外套上沾到的痕迹快速处理了一遍，重新回到楼下。

那段时间，别墅里所有人都被刘明辉之前的怒气搅得心神不宁。

没有人会特意盯着一个助理去了哪里。

赵刚听完以后，沉默了几秒，又问：“那热搜呢？也是你计划里的一部分？”

“是。”何清这次没有回避。

“我本来就没想让他安安静静地死。”

她抬起眼，眼底终于有了一点真正的锋利，“姐姐死的时候，没人替她说话。那他死的时候，也不该还有那么多人替他说好话。”

【天道好轮回，善恶终有报。】

【既然上天不收他，我就来做收他的这个人。】

赵刚缓缓吐出一口气。

到这里，这场审讯其实已经收得差不多了。

动机、过程、准备、热搜，全都对上了。

等下就是安排人去按照何清说的动线确认下证据就可以了。

他看了陈继东一眼，两个人谁都没说话，但都知道，这案子该往上汇报了。

*

半小时后，王局办公室的门被敲开。

赵刚和陈继东一前一后走进去的时候，王局刚放下手里的电话。

他抬起头，先看了两人一眼，又看了看赵刚手里夹着的那叠材料，眉头微微一动。

“坐吧。”他说。

赵刚没废话，坐下之后就直接开始汇报。

整个汇报说完，办公室里安静了几秒。

王局没立刻说话。

他靠在椅背上，手指在扶手上轻轻敲了两下，像是在把这整件事重新过一遍。

昨天，他才点头让三队过去帮忙。

当时在他的预估里，最多也就是让三队从旁边撕个口子，帮二队把已经绷住的案子往前推一推。

谁也没想到，这才过了一天，案子不但翻了前提，连真凶都认了。

这速度怎么一下子这么快？

王局抬起眼，看向赵刚，语气里第一次有了点压不住的意外。

“也就是说，”他缓声道，“昨天才让三队过去帮忙，今天案子就破了？”

赵刚点了点头：“是。”

王局语气中带着几分激动，“热搜那边先盯住，舆情和公司反应都得有人跟上。何清这边物证也是，要不到了检察院环节还会被打回来。”

交代完案子本身，王局的目光重新落回赵刚和陈继东脸上，又往下问，眼神灼灼。

“说说吧，怎么这么快就破案了？”
