# 第26章 前提就一定对吗

“情况大家都清楚了。案子线索多，但我们不能乱。”

赵刚把手里的记号笔在指间转了半圈。

“现在三队过来支援，对我们来说是实打实的助力。我先替二队说一句，谢谢。”

陈继东摆摆手，“客气了，兄弟。”

赵刚没有给人继续发散情绪的时间，转头就在白板上又添了几笔，把原本并列的三条线往下继续拆开。

“家庭线继续推进。”他点了点苏琳和刘泽的名字。

“苏琳那边，要盯紧她的舆论动作、账户异动、律师接触和她这两天所有对外表述，别让她用一副受害者的样子把节奏全抢走。”

“刘泽那边，把他案发前后的活动轨迹、债务催收线、签章接触链再往细里捋，他和死者那场争执的完整内容也要尽快补充完善。”

“公司线也不要停。”赵刚的激光笔又点向王建。

“王建手里的账、项目、基金、审计，全都继续往下挖。慢也得挖，不能因为今天出不了结果就先放着。”

“现场线又要继续做细。归根结底的一切还是要看现场的线索。”

他说到这里，目光在屋里每个人脸上扫了一圈，语气依旧很沉。

“所有人都尽可能地把手里负责的部分尽可能地做详细。证据会自己说话。”

会议室里几个人同时应了声“是”。

赵刚转头继续说道：“二队原本的人员分工不变。三队这边，如果老陈你们愿意，可以先根据自己的意愿选择切入口。”

“要是你们这边有什么想法，随时提。只要能把案子破开，我们这边都配合。”

这话说得很公允，也把台阶给足了。

陈继东点了下头，没急着当场拍板，只道：“行，我们先内部碰一下，十分钟后给你们回复。”

散会后，陈继东带着江明、刘航元和时菱退到会议室外侧的走廊尽头，几个人站定之后，他先低声问：“怎么样？你们有什么想法？”

刘航元第一个开口：“我可以先去梳理刘泽和苏琳两个人们案发前后的通讯、定位和资金流水情况。”

陈继东“嗯”了一声，看向时菱。

她抬起眼，“我想先回现场。”

“现在这案子的可能性太多了。”

“我觉得，越是这种时候，越不能先被现在的结论牵着走。我想先去别墅里看一下，再接触一下现场相关的人。”

刘航元下意识问：“你是觉得现场还有关键线索没被发现？”

“有可能。”时菱没有把话说满。

江明眼睛微微一亮，像是被这句话戳中了：“那我跟你去。”

刘航元抱紧手里的本子，语气一下子提了起来，“那我也先一起去看下，免得我们队跑两次。”

陈继东看了他们两个一眼，没再多说，直接拍板。

“行，那就我们四个先回别墅。老赵那边我去打个招呼，别到时候咱们突然插过去，现场那边又得重新交接。”

他说完便转身往会议室那头走。

几分钟后，陈继东折返回来，抬手一挥：“走，去刘家别墅。”

*

半小时后，一行人到了刘家别墅外。

陈继东出示了证件。

守在门口的年轻警员立刻抬手放行，语气里带着一种连轴转之后的沙哑疲惫：“陈队，里面现场组的人还在，二楼和书房那边也都留着人。”

“辛苦。”陈继东点了下头，没多废话，带着时菱几人直接往里走。

迎出来的是个留守现场的二队警员，三十来岁，眼底乌青很重。

见到他们先是叫了声“陈队”，紧跟着目光便不由自主地落到了时菱身上。

【就是她？会议室里那个顾问？这么年轻，看着比我表妹大不了几岁。】

【赵队居然真让她进现场，看来前面那个案子她多半不是只会站在旁边听热闹。要是真能在这儿看出点别的，那二队这三天也算没白熬。】

【不过现场这地方，跟会议室里动动嘴可不是一回事。该查的都查过了，现在再回来，多半也没有什么新发现。】

他心里这么闪了一下，面上倒还客气：“赵队刚打过招呼了，说你们要重新过一遍现场。书房那边我们尽量没再动，不过该提的物证都已经提过了。”

“行，你带路。”陈继东说。

警员一边往里走，一边把前面已经查过的情况重新顺了一遍：“死者是在一楼书房里被发现的。”

“房门当时打不开，窗户从里面扣着，后来是物业和开锁的人一起到场，才把门打开。”

“凶器就是书桌上那把裁纸刀，现场没有发现外部强行闯入痕迹，别墅外围监控又正好被暴雨打出了盲区。”

这些内容，时菱在会议室里都听过。

她没有急着进书房，先站在走廊口看了一眼整个一楼的格局。

客厅、餐厅、通往后花园的玻璃门，还有沿墙而上的楼梯。

书房在一楼西侧，门框和墙板用的是同一色系深木。

几个人走到书房门口。

门开着，书房内部已经没有尸体，但那种案发时留下的暴烈痕迹并没有真正消失。

厚重的书桌、靠墙书柜、地毯上的暗沉印记，一进门就能把人重新拽回那个雨夜。

留守现场的警员下意识又介绍道：“死者当时就是倒在书桌前这一块，颈部创口很深，血喷到了桌腿和地毯边缘。”

“门是从里面锁上的，窗也是从里面扣上的，所以我们推测，是熟人作案。”

他说这话的时候，旁边两名现场人员一个在整理材料，一个在低头看记录，谁都没抬头。

【这案子到底什么时候能破啊？这周末不会又不能休假了吧？】

【真是邪了门了，这么多年也没见到一个密室杀人案。凶手到底怎么做到的呢？】

时菱终于意识到了她一直觉得有些不对的地方了——所有人都在强调这是密室杀人。

可是真的一定是密室吗？

时菱语速飞快地问道：“最先判断这扇门是从里面反锁的，是谁？”
