# 案件二：董事长密室凶杀案

## 基本信息
- **章节范围**：第20-38章（文件 020-037）
- **案件类型**：密室凶杀案
- **受害人**：刘明辉（董事长/富豪）
- **凶手**：何清（不起眼的次要人物）
- **动机**：旧怨复仇，何清长期隐忍策划

## 案件推进

### 嫌疑人排查
1. **明面嫌疑人若干**：公司内部竞争者和家庭关系人均有动机
2. **密室设定**：暴雨夜，门窗反锁，初步判断为密室杀人
3. **沈睿出场**：二队海归博士，最初不服时菱

### 线索链
1. 所有人聚焦密室如何形成时，时菱提出**门锁前提可能本身就有问题**——锁可能在被发现前就已被破坏
2. 时菱将视线从"最像凶手的人"转向"最容易被忽略的人"
3. 何清从边缘人物中被挖出——不在初始嫌疑名单上，但行为模式异常
4. 证据逐步闭环，何清认罪

### 关键破案点
- 密室前提被推翻：不是"凶手如何在密室中杀人"，而是"密室本身是否为伪造"
- 何清的行为基线表现出回避特定话题的异常

## 案件收尾
- 案件引发社会关注，上热搜
- 沈睿开始对时菱的能力有所认识（但尚未完全服气）

## 系统结算
- 48小时限时奖励
- 现金奖励

## 人物成长
- 时菱：展示"质疑前提"的核心推理能力
- 沈睿：海归博士vs实战型顾问的对比线开启
- 时菱从三队"试用"状态逐步被接受
