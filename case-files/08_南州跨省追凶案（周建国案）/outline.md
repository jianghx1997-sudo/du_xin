# 案件八：南州跨省追凶案（周建国案）

## 基本信息

- **章节范围**：第127章至第144章（文件 128-145）
- **案件类型**：在逃命案嫌疑人藏匿、跨省协作、案中案
- **受害者一**：周建国，南州退休学校门卫，独居老人
- **受害者二**：徐广明，岳川司机，赵诚逃亡途中灭口对象
- **真凶**：赵诚，南州在逃通缉人员
- **窝藏关联人**：赵桂兰，赵诚母亲
- **核心动机**：赵诚入室盗窃时被周建国撞见并认出，害怕报警而杀人；逃亡途中又因司机徐广明怀疑他是通缉犯，再次灭口。
- **本案一句话卖点**：林韵一句“楼上半夜放佛经，好像不止一个人”，牵出藏在老破小里的南州命案逃犯。

## 案件推进

### 第一阶段：生活异常

1. 林韵向时菱求助，称楼上半夜反复播放老歌和佛经，物业提醒后只安静两天。
2. 名义租户赵桂兰登记为独居外地阿姨，但林韵听见过疑似男声和咳嗽。
3. 时菱陪林韵上门，通过赵桂兰心声听到“赵诚”“南州”“通缉令”等关键词。
4. 时菱没有私自查案，而是把林韵带到楼下小超市避险，并联系陈继东。

### 第二阶段：锁定赵诚

1. 三队根据“南州”“赵诚音近”“重大刑案在逃”等方向筛查协查通报。
2. 赵诚右眼下方黑痣等特征与通缉资料吻合。
3. 赵诚准备从小区后门、电动车棚和菜市场方向逃离。
4. 顾晏廷、张海涛等人布控抓捕，赵诚落网。

### 第三阶段：南州周建国案落地

1. 南州刑警蒋建明带卷宗赶到江城，说明周建国案情况。
2. 南州前期已经通过楼道消防箱后烟头 DNA、案发前踩点监控、死者手表销赃记录等，将赵诚列为重点嫌疑人。
3. 赵诚落网后，身份通过指纹、人像和体貌特征核验。
4. 审讯中，时菱从赵诚对佛经、老歌和周建国的恐惧反应切入，推动其承认周建国案。

### 第四阶段：岳川徐广明案

1. 赵诚交代逃亡路线时，对“司机”和“车”反应异常。
2. 时菱判断他在南州逃往江城的途中可能还藏着另一条人命。
3. 结合路线时间缺口和岳川男司机徐广明案，警方开展补查。
4. 顾晏廷参与残缺指纹比对，江城快速确认赵诚与徐广明案关联。
5. 赵诚最终承认杀害徐广明，并供述推车入河等细节。

## 证据链

1. 林韵记录的噪音、投诉和疑似男声，证明楼上“独居阿姨”状态不正常。
2. 赵桂兰心声、口音、登记异常和通缉信息筛查，锁定赵诚身份。
3. 南州周建国案中的烟头 DNA、踩点监控、死者手表销赃，证明赵诚是周建国案嫌疑人。
4. 赵诚对逃亡路线和司机的异常反应，牵出徐广明案。
5. 岳川线残缺指纹、车辆和赵诚口供，补齐第二起命案证据链。

## 时菱发挥点

- 从朋友生活求助中保持警觉，但守住顾问边界，没有私自上楼硬查。
- 通过赵桂兰和赵诚心声捕捉关键词，再用正规程序交给三队筛查。
- 在赵诚已承认周建国案后，仍注意到“司机”反应不对，推动发现第二起命案。
