# 案件七：林可可死亡案

## 基本信息

- **章节范围**：第104章至第126章（文件 105-127）
- **案件类型**：网络舆论高度关注的主播死亡案、伪装意外/自杀、职场控制欲
- **受害者**：林可可，星途传媒美妆区头部主播
- **真凶**：秦正，星途传媒运营总监，林可可经纪人和早期伯乐
- **核心动机**：林可可准备不再续约并离开星途，秦正无法接受自己一手培养的人脱离掌控。争执中他抢录音手机，导致林可可摔倒撞击茶几，随后为伪造现场给她灌安眠药并丢弃手机。
- **社会影响力**：林可可粉丝众多，案件迅速发酵为全国级舆论事件。
- **本案一句话卖点**：全网都在骂姜予，时菱却从一只被丢进电梯井道的手机里，把真正害死林可可的人钉回了审讯室。

## 案件推进

### 第一阶段：现场与误导

1. 林可可在公司休息室死亡，现场有红酒、安眠药和摔倒痕迹。
2. 姜予是最后一个公开进入休息室的人，又与林可可有“死对头”人设，成为舆论焦点。
3. 时菱听到姜予心声，确认她真心痛苦，且她离开时桌上没有药瓶，不是凶手。
4. 现场被人为摆过：药瓶位置刻意、林可可手机消失，说明有人伪造过自杀或意外现场。

### 第二阶段：排查公司内部

1. 徐知行因合同差价和商务回扣浮出水面，有经济犯罪嫌疑。
2. 徐知行不是杀害林可可的人，但他的职务犯罪线另案移交。
3. 秦正回到视野。林可可合同即将到期，续签谈判成为关键矛盾。
4. 时菱在问询秦正时捕捉到“电梯井道”关键词，判断林可可手机被他丢在那里。

### 第三阶段：关键物证

1. 张海涛带人去电梯井道找手机，找到摔碎的林可可手机。
2. 刘航元从严重损坏的手机中恢复出五分四十秒录音。
3. 录音记录秦正与林可可的续签争执、抢手机和倒地闷响。
4. 江明在手机机身上提取到秦正右手拇指、食指、中指三枚指纹。

### 第四阶段：审讯反杀

1. 秦正承认争执和意外摔倒，但试图把案件说成单纯意外后慌乱伪造现场。
2. 顾晏廷用法医和生理常识指出，林可可被灌药时还存在吞咽反射，不可能已经完全死亡。
3. 秦正明知林可可还有生机，却选择给她灌药、关机丢手机、伪造现场。
4. 警方在四十八小时内破案并对外通报。

## 证据链

1. 姜予离开时桌上没有药瓶，排除她直接伪造现场。
2. 现场摆放、消失的手机和秦正动线，指向公司内部二次进入者。
3. 电梯井道中找到的手机，是本案关键物证。
4. 手机录音、时间戳、秦正指纹和现场痕迹形成闭环。
5. 法医判断与安眠药吞咽事实，推翻秦正“人已经死了才慌乱处理”的说法。

## 时菱发挥点

- 通过姜予心声和现场细节，避免舆论把无辜者推成凶手。
- 从秦正心声中捕捉手机位置，推动找到核心证据。
- 将读心结果包装为行为反应、物品缺失、现场逻辑和嫌疑人焦虑点。

## 案后余波

1. 江城公安发布警情通报，网友从质疑警方转向讨论秦正、直播行业和姜予冤屈。
2. 姜予直播讲述她和林可可真实友情，舆论反转。
3. 王雅、临川家长、许知言母亲等人先后用公开方式证明时菱确实帮过人。
4. 江城市局宣传口建议时菱开设实名账号，定位为江城市公安局特邀心理侧写顾问，用于反诈、防拐、防谣等科普。

## 系统与后续状态

- 系统结算现金十万元。
- 心声捕捉范围永久拓展至两米。
- 时菱个人账号建立，年轻活粉基础开始形成。

## 后续可回收点

1. 姜予可作为舆论创伤后的回归人物。
2. 时菱个人账号可承接后续反诈、科普和求助入口。
3. 本案让时菱名声从江城内部走向更广公众视野。
