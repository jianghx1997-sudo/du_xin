# 案件六：春山小馆危化品伤人案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

## 基本信息

- **章节范围**：第87章至第103章（文件 088-104）
- **案件类型**：现行犯、蓄意伤害未遂、公共场所危化品袭击
- **受害目标**：叶晴，春山小馆女店员
- **嫌疑人**：灰衣男人，叶晴通过本地兴趣群认识的纠缠者
- **核心动机**：叶晴与对方吃过两次饭后拒绝发展关系，并有了新男友。嫌疑人将正常社交曲解为“答应交往”，认为叶晴背叛他，携带工业强碱清洗剂准备毁掉她的脸。
- **本案一句话卖点**：排队吃饭时，时菱从人群里提前听见恶意，顾晏廷当场出手，把一场本该毁掉女孩人生的袭击压在瓶盖拧开的前一秒。

## 案件推进

### 第一阶段：春山小馆排队

1. 时菱休假去春山小馆吃饭，现场人多、排队长。
2. 她听到灰衣男人心声，判断对方目标是店门口的叶晴，包里有危险液体。
3. 时菱体能差，无法独自制伏对方，只能先观察、稳住现场。
4. 顾晏廷刚好到达，时菱用手机备忘录把危险信息递给他。

### 第二阶段：当场制服

1. 灰衣男人靠近叶晴，准备拧开瓶盖。
2. 顾晏廷在关键瞬间扣住他手腕，将人压制。
3. 时菱提醒人群后退，避免危险液体造成二次伤害。
4. 辖区派出所到场，危险液体被隔离，叶晴未受伤。

### 第三阶段：舆论发酵

1. 现场视频上热搜，最初关注点在顾晏廷制服嫌疑人的动作。
2. 后续更多角度视频被发出，网友发现是时菱先盯住灰衣男人，再递手机提醒顾晏廷。
3. 平台和警方宣传口注意避免传播叶晴正脸，防止对受害者二次伤害。
4. MCN公司、外地同行、企业和熟人都开始关注时菱，出现“抢人”趋势。

### 第四阶段：江城市局正式留人

1. 王局和郑局意识到时菱的价值正在被外界看见，必须尽快稳定她在江城的位置。
2. 郑局长亲自与时菱谈话，代表江城市公安局请她留下来。
3. 局里通过班子会，正式确认时菱在三队的特邀顾问身份。
4. 叶晴到市局送锦旗，讲述自己被纠缠的经过，并决定去母亲所在城市重新开始。

## 证据链

1. 现场危险液体和瓶身等物证，证明灰衣男人有现实实施条件。
2. 灰衣男人与叶晴的聊天、纠缠、蹲守记录，证明长期骚扰和报复动机。
3. 现场多角度视频和证人证言，证明顾晏廷制止行为发生在袭击前一刻。
4. 叶晴陈述和警方检测，补强嫌疑人主观恶意与危险后果。

## 时菱发挥点

- 在公共场所提前捕捉危险心声，并没有鲁莽行动。
- 将危险信息以手机文字方式传递给顾晏廷，既快又不打草惊蛇。
- 控制现场秩序，提醒群众后退，减少二次伤害风险。

## 感情线和主线推进

- 顾晏廷看时菱朋友圈后到春山小馆，表面是“刚好碰上”，实际是克制的主动靠近。
- 两人在案后吃面，顾晏廷提出带时菱做基础训练。
- 时菱确认自己听不到顾晏廷心声，这是全书长期伏笔。
- 顾母通过热搜视频注意到时菱，顾晏廷对母亲第一次松口“心里有数”。
- 时家看到时菱和顾晏廷同框后再度误判，时薇到市局闹，被三队和叶晴送锦旗形成强烈对比。
