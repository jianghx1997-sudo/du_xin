# 案件九：陆承安十七年旧案

> 本案已破。后续再提及时，只需简要回扣证据和影响，不要重复长篇解释祁远动机。

## 基本信息

- **章节范围**：第145章至第180章（文件 146-181；第159章至第166章为南湾镇纵火案，已单独拆分为第十案）
- **案件类型**：十七年前命案积案重启、跨地协作、旧案复盘
- **主办单位**：南州市公安局刑侦支队
- **协助单位**：江城市公安局刑侦三队
- **受害者**：陆承安，十七年前在南州城郊旧厂区附近被害
- **真凶**：祁远，陆承安当年帮助过的人
- **核心动机**：祁远将陆承安的善意帮助扭曲为羞辱，又嫉妒陆承安拥有事业、婚姻和宋清妍的爱。案发前几天陆承安真心替他高兴并介绍生意，反而刺激了祁远长期积压的自卑和怨恨。
- **本案一句话卖点**：十七年旧案里最可怕的不是陌生恶意，而是被帮助者把善意嚼成仇恨，再把凶器藏在身边十七年。

## 旧案已确认事实

1. 陆承安死于多处刀伤，部分伤口发生在致命伤之后，说明凶手具有强烈泄愤情绪。
2. 现场财物没有明显翻动，手机、钱包、车钥匙仍在，不像单纯抢劫。
3. 陆承安案发前接到公用电话后临时前往旧厂区。
4. 案发后，宋清妍送给陆承安的银色领带夹失踪。
5. 宋清妍多年未再婚，独自抚养儿子长大。第152章问询中，时菱通过当面观察和心声确认她真心希望破案，不是凶手。
6. 陆承安父母早年受流言影响怀疑过宋清妍，后来已把她当亲女儿。

## 案件推进

### 第一阶段：南州求助

1. 南州蒋建明因周建国案见识到时菱能力，请江城协助查看十七年前积案。
2. 江城明确时菱顾问身份和协助边界，顾晏廷同行。
3. 南州专班按组分工，二组负责重点关系人复核，时菱和顾晏廷加入。

### 第二阶段：排除既有烟雾弹

1. 宋清妍线：确认她不是凶手，也不是知情人；她是被流言伤害十七年的家属。
2. 赵文启线：他是早年把怀疑引向宋清妍的人，但只是恶意揣测，不是凶手。
3. 孟唯良线：隐瞒项目争执和陆承安死后接手项目带来的压力，但不在场证明和记录能对上。
4. 方钧线：隐瞒金源茶楼私下谈项目和不体面的商业竞争，但案发当晚时间线能对上。
5. 二组复核大量关系人后，时菱意识到真凶可能不在最初最显眼的关系框架里。

### 第三阶段：转向祁远

1. 二组外出复核外地关系人，第三站来到陵川见祁远。
2. 祁远表面感激陆承安，心声却暴露强烈厌恶、嫉妒和对案发当晚细节的知情。
3. 他知道领带夹，也知道陆承安案发当晚发生了什么，但表面滴水不漏。
4. 警方没有凭心声行动，而是依法补查祁远近年生活和纠纷材料。

### 第四阶段：旧柜子和铁证

1. 祁远公司前员工何彬的劳动仲裁材料反复提到一个祁远异常看重的旧实木柜。
2. 何彬曾从柜门缝里看见旧报纸和透明盒子里的银色小东西。
3. 旧照片拍到柜门缝中夹着“南州旧厂区杀人案”字样的旧报纸。
4. 蒋建明依法申请搜查，警方在祁远公司小休息间旧柜子里找到旧报纸、透明盒子和陆承安失踪的领带夹。
5. 祁远被带走前，时菱从他心声和目光反应里判断柜子底部还有东西。
6. 警方重新检查旧柜子底板，在暗格中找到旧布包裹的折叠刀。

## 核心证据链

1. 领带夹：陆承安案发后失踪，在祁远旧柜子中出现，证明祁远与案发后物品有关。
2. 旧报纸和照片：证明祁远长期关注并保存陆承安案相关材料。
3. 折叠刀：旧柜子暗格中发现，是本案关键凶器。
4. 血迹 DNA：刀上血迹与陆承安留存血样支持同一来源。
5. 残缺血指纹：刀柄内侧残缺血指纹指向祁远右手拇指。
6. 祁远供述：用公用电话骗陆承安到旧厂区，作案后拿走领带夹，并长期保存刀、领带夹、旧报纸和照片。

## 时菱发挥点

- 通过当面观察和心声辅助排除宋清妍等被旧案流言伤害的人。
- 在既有重点关系人不断排除后，提醒不能只困在原有框架里。
- 从祁远口供和心声反差中发现真正嫌疑。
- 在旧柜子找到领带夹后，没有停在半证据上，而是通过祁远反应发现暗格里的折叠刀。

## 案后余波

1. 宋清妍和陆承安父母得知真相，迟到十七年的交代终于落地。
2. 系统将南湾镇老街人为纵火案与陆承安旧案合并结算。
3. 时菱获得现金十万元、心声范围从两米升级至三米，并获得道具“感同身受”。
4. N 省公安厅向江城市公安局发感谢函，江城王局、郑局意识到时菱已被外省公安系统看见。
5. 江城市局后续举行内部表彰大会，但时菱仍是顾问，不能写成正式民警立功授奖。
