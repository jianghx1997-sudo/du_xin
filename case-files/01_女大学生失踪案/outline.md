# 案件一：女大学生失踪案

> 本案纲按当前本地最终稿整理。章节正文仍为最高依据。

## 基本信息

- **章节范围**：第5章至第19章（文件 005-019）
- **案件类型**：女大学生失踪、诱骗、非法拘禁、故意伤害相关
- **受害者**：王雅，江城大学女大学生
- **真凶**：谭永，江城大学化学院大三学生
- **重要共犯/被利用者**：孙强，王雅前男友
- **核心动机**：谭永因自卑、嫉妒和畸形占有欲，把王雅当成自己可以用债务换来的对象；王雅拒绝后，他利用孙强实施诱骗和绑架。
- **本案一句话卖点**：所有人都盯着“不良男友”，时菱却从心声和反应里揪出藏在背后的高智商大学生。

## 案件推进

### 第一阶段：时菱进入警局

1. 时菱在时家断亲后主动找到陈继东，提出自己能以心理学、微表情和行为侧写协助办案。
2. 陈继东起初不信，但王雅父母情绪濒临崩溃，案件又迟迟没有突破，最终给了她一次机会。
3. 王雅前男友孙强是明面嫌疑人。他态度差、有债务、和王雅有争吵，最容易被怀疑。

### 第二阶段：从孙强牵出谭永

1. 时菱接触孙强时听到“谭永”这个名字，发现孙强并不是单独作案。
2. 警方通过通话记录、网吧轨迹和案发前后三秒通话，把谭永从背景里拎出来。
3. 谭永表面是贫困、老实、成绩好的学生，辅导员和周围人都认为他没有作案条件。
4. 时菱用基线反应测试和问题施压，听到谭永对王雅的恶意，判断他是主导者。

### 第三阶段：救出王雅和补证

1. 时菱通过谭永心声和外部反应，判断王雅被藏在谭永老乡家的空置房里。
2. 警方联系谭永老家派出所核查，确认城南长丰村有一处带地窖的废弃平房。
3. 特警赶到后从地窖中救出王雅，王雅已经虚弱到接近极限。
4. 谭永和孙强互相推责。警方固定 MP3、药瓶、乙醚瓶口指纹、毛发毒物残留、制毒文献等证据。
5. 证据链闭环后，谭永供述作案过程。

## 证据链

1. 孙强与王雅的关系、债务和最后接触，说明他有重大嫌疑。
2. 孙强心声、三秒通话、网吧轨迹，指向谭永在背后操纵。
3. 谭永心声暴露王雅藏匿地点，警方经老家派出所核实后救出受害者。
4. MP3、药瓶、乙醚瓶口指纹、毛发毒物残留和制毒文献，证明谭永并非被孙强胁迫，而是主导者。
5. 王雅获救后的伤情和现场情况，固定非法拘禁和伤害事实。

## 时菱发挥点

- 用读心能力首次切入案件，但对外包装为心理学、微表情、行为侧写。
- 从孙强身上听到“谭永”，把警方从明面男友线带向真正主谋。
- 在王雅生命危险迫近时，通过谭永反应和心声推断藏人地点。

## 人物变化

- **时菱**：从被家族抛弃，到第一次确认自己的能力能救人。
- **陈继东**：从不信到愿意给机会，成为时菱进入警方体系的第一个支持者。
- **刘航元、张海涛等三队成员**：开始意识到时菱不是来添乱的人。
- **王雅**：被救出后成为后续可回归的受害者回声。

## 后续可回收点

1. 王雅康复后向时菱道谢，可作为时菱“救到活人”的情绪回扣。
2. 本案建立时菱对外包装方式：心理学、微表情、行为侧写。
3. 本案是三队信任时菱的起点，后续写陈继东护她时可回扣。
