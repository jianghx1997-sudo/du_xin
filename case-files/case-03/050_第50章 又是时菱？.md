# 第50章 又是时菱？

陈继东没耽误，转头就往王局办公室去。

王局办公室的门虚掩着。

陈继东敲了一下，推门进去：“王局。”

王局刚放下电话，抬眼看他：“怎么样？”

陈继东开门见山地汇报：“时菱通过审问，找到了店面和背后主犯马会琴。我们刚从马会琴那边也试出结果了。她人没松口，但反应已经够用了。他们在三年前还卖过孩子，基本可以确定是卖到了临州。时菱还说或许可以通过技术手段搜查马会琴的微信好友和电话电话记录，重点关注三年前位置在临州的账号。”

陈继东也算是据实汇报，当然，他把时菱点出来，也是想委婉地提醒一下王局，让王局尽快给时菱办手续。

王局原本还靠在椅背上，听到“时菱刚试出来”这句，坐姿一下正了些。

他这几天已经听过太多次这个名字了。

而现在，这一次又是她先审出来的。

可震惊归震惊，王局心里那根弦并没有松。

临州这条线，毕竟还只是时菱从马会琴的反应里逼出来的方向，不是已经落在纸上的硬证据。

真要把人和资源一下全压过去，一旦压偏，耽误的就是找孩子的时间。

可时菱，的确给了太多次的惊喜。

王局手指在桌面上轻轻敲了一下，最终做出了决定，“双线并着走。”

陈继东立刻应声：“您说。”

“第一，马上联系临州警方。把我们这边的情况同步过去，讲清楚江城抓到了团伙关键成员，请他们连夜先把相关协查接起来。先摸排下三年前异常收养、补录身份、可疑儿童落户等情况。”

“明白。”

“第二，技术口立刻上。”王局抬眼看他，“把马会琴现在这部手机、旧手机、旧号、旧设备能恢复的都恢复。重点关注三年前的微信好友、语音、通话、转账、红包、删掉的记录，全部过一遍。尤其是临州方向，平时没什么文字、但语音和通话不正常的，单独拎出来。”

“第三，二队那边继续审问，不要停下来。能挖出多少信息就挖出来多少。”

“明白！”

*

技术办公室的灯全亮着，键盘声密密麻麻。

临州那边的电话刚接上，江城这边的协查函和基础案情已经先发了过去。

刘航元抱着电脑往技术科跑，边走边还在通话：“对，三年前开始拉，不光拉现在这台，旧设备、旧号码也一起看。微信优先，语音和通话频繁但文字少的，也都标出来……对，临州方向单独标出来。今晚我们先把总数拉出来，明早再继续核实。”

江明那边也没闲着，带着人重新回窝点和店面周边，把前后几条巷子的监控再往前倒。

如果马会琴三年前真走过这条线，她不可能一点痕迹都不剩。

赵刚也已经接上来了。

他原本带着二队盯老孙那边，老孙这个人口风很紧。问了半天，又是一点话都不说。正当他焦虑没什么线索的时候，就听到陈继东说他们这边的进展。

赵刚都有一瞬间恍惚，一般儿童拐卖案都特别难审问，因为这是重罪，没几个人愿意承认。

可时菱怎么做到的？不仅运气好、能发现线索，短短不到一天时间，连背后主使都找到了，还知道了这么多信息。

难道这就是天生适合在警局的人？

赵刚下意识的抬头去看了一眼沈睿的反应，而这一次沈睿低着头像是在思考，应该是没有钻牛角尖，赵刚放心了。

看着三队进展这么快，赵刚心里那点斗志也上来了，他们也不能落下！

他转头就带着队里的同事回到了审讯室。

*

另一边，技术科里也很忙。

马会琴的手机被拆出来放在桌上，几台机器同时在跑恢复。

一个技术员盯着屏幕，眼睛都快不眨了：“这人清得挺干净，聊天记录不多，最近这几年留字也很少。”

刘航元站在后面：“她这种人不可能没留后手，往前翻。”

“在翻了。”

又过了十来分钟，另一个技术员抬头：“有点东西。”

刘航元立刻过去。

屏幕上跳出来一串旧数据，时间断断续续地卡在三年前。

联系人里没有什么明显备注，大多是昵称和空白头像，看上去平平无奇。

可其中有几个号，文字记录完全没有，语音通话却在几天内重复出现，而除去那几天，其他时间反倒没什么联系了。

技术员说：“这几个真是高度可疑，平时没联系，真联系的时候都是语音。再看登录地，有两个号长期在临州一带活动。”

刘航元眼神一下亮了：“确实嫌疑很大，我们赶紧顺着实名和设备往下挖。”

“好。”

*

夜已经很深了。

整层办公区却依旧忙碌。

有人拿着打印出来的联系人名单来回穿梭。

有人抱着盒饭站在走廊边吃，吃两口又放下接电话。

审讯室门一开一关，灯光透出来，照得地砖都是冷白的。

审讯室里面是二队的人，时菱这回没再进去。

她知道，她能做的已经做的差不多了。

再往下，就是警方该把这条线一点一点拽实的时候。

陈继东远远看见她还坐着，脚步顿了一下，最后走过去把一盒没拆的牛奶放到她手边,“先垫一口。这两天你也辛苦了，本来说要给你放假，结果又没放成。等过了这两天，你好好休息一下。”

时菱点了点头。

她确实有点累。

就在这时，走廊另一头忽然传来一阵急促脚步声。

有人一路小跑着过来，在值班台前停下，喘着气报了一句：“临川的人到了。”
