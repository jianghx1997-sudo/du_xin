# 案十二：不上学的孩子（暂定）

> 轻量案纲。当前仅记录作者已确认方向，后续案件卡和章纲待作者确认后扩展。

## 基本信息

- **案件名称**：不上学的孩子（暂定）
- **案件类型**：未成年人受害、家庭教育误导、权威人物侵害
- **当前入口**：一名母亲带着不肯上学的儿子到市局求助，现场看起来像家庭教育问题。
- **核心受害者**：十三岁左右男孩，近期逃学、失眠、疑似偷钱和去网吧。
- **核心方向**：孩子不是故意不上学。校园霸凌是第一层原因，更深层的恐惧来自母亲请来的退休教师王明生。
- **真凶**：退休教师王明生。其利用教师身份和家长信任侵害程嘉佑，在职期间也曾侵害其他男生。

## 当前正文进度

- 已写至第231章《再也不敢了》。
- 校园霸凌部分完成处分和案后变化；“感同身受”已经对程嘉佑的全部加害者生效。
- 王明生六十二岁，刚退休不久。第231章末，陈继东、时菱和顾晏廷在何敏家中与王明生见面，尚未正式询问。

## 已确认的后续发现方式

1. 王明生已经经历数日“感同身受”，不断承受程嘉佑遭受侵害时的身体感受和恐惧、屈辱，精神状态变差，面对警方时心理防线和自控能力都比平时弱。
2. “感同身受”只负责制造异常反应、削弱王明生的伪装，不能作为现实证据，也不能代替警方调查。
3. 时菱通过王明生面对警察时的关注点、异常放松、主动辩解、说辞矛盾和表层心声确认危险；读心后仍须经过外部观察和核对，不能当场直接定罪。
4. 程嘉佑在正式询问中说出王明生身上正常情况下无法看到的隐蔽身体特征，暂定为隐蔽部位的特殊疤痕或胎记，具体形态待正文确定。
5. 警方依法核实该身体特征，证明程嘉佑知道“非亲历不可知”的细节，作为其陈述真实性的重要印证。

## 已确认的证据方向

1. 程嘉佑对侵害时间、地点、经过、王明生固定话术及隐蔽身体特征的稳定陈述。
2. 何敏的工作排班、补课转账和聊天记录，证明王明生与程嘉佑多次独处及作案机会。
3. 程嘉佑在补课后的失眠、反复洗澡、抗拒接触、成绩下降和轻生倾向，由何敏、老师及心理评估予以佐证。
4. 王明生在谈话或询问中承认以检查发育、纠正坐姿等理由发生身体接触，但否认猥亵目的，形成部分承认和前后矛盾。
5. 后续寻找互不串联的旧受害者；多名受害者独立说出相似作案方式、威胁话术及同一隐蔽身体特征。
6. 旧学校档案中保留家长投诉、内部处理记录或王明生亲笔情况说明，用于印证旧受害者陈述和长期作案模式。

## 后续红线

1. 不给王明生安排偷拍视频、照片或装满犯罪资料的存储设备，证据依靠被害人陈述与现实间接证据闭环。
2. 程嘉佑说出的隐蔽身体特征不能由时菱诱导，必须在规范询问中由他主动讲出。
3. 王明生心理防线较弱不等于立刻完整招供；可先出现主动辩解、口误和前后矛盾，再由顾晏廷等人依法询问。
4. 时菱始终是顾问，只负责观察、提出疑点和协助判断，正式询问、检查、调证和侦查由警方完成。

## 已确认红线

1. 第一章只写到时菱路过时听见孩子“不想活了”，不提前揭示侵犯、老师或其他受害者。
2. 周静本案暂不出场，只在队内消息里作为即将加入三队的伏笔。
3. 时菱不能越权，前期只能观察、提醒风险，不能直接定性。
4. 孩子和母亲的情绪都按普通人状态写，避免把对话写成案情说明。

- 引出三队未来将优先参与重大疑难案件，并获得更灵活的介入机会。
- 提到周静即将加入，不让她参与本案开局。
- 用一个看似普通的“孩子不肯上学”事件作为新案入口。
