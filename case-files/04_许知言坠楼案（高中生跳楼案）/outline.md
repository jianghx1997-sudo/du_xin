# 案件四：许知言坠楼案

> 现行历史案纲。本轮核对至第285章，案件本身的历史事实保留；道具与人物的当前状态看根目录追踪表。仅作参考，不启动旧代写、审查或自动归档流程，也不授权轻修时删去作者重复内容。

## 基本信息

- **章节范围**：第54章至第63章（文件 054-063）
- **案件类型**：高中生坠楼案、伪装自杀、教育腐败
- **受害者**：许知言，江城一中高三尖子生
- **真凶**：杜明川，负责保送相关工作的学校老师
- **核心动机**：杜明川收受周妍家现金，把周妍顶进保送名单。许知言发现保送名单和材料异常，准备举报，杜明川为压下事情将她逼上天台，抢夺证据时从背后推搡致其坠楼死亡。
- **本案一句话卖点**：所有人都说她压力大想不开，时菱却把一场“自杀”查成了校园保送黑幕下的灭口。

## 案件推进

### 第一阶段：校方口径和许母求助

1. 许知言坠楼后，学校和部分人倾向于解释为学习压力、自杀。
2. 许母不相信女儿会自杀，在学校门口拉横幅。
3. 时菱进入学校调查，先从许知言近期状态异常和保送名单变化切入。

### 第二阶段：保送黑幕浮出

1. 班主任梁芳知道保送名单有问题，却因为害怕丢工作、害怕得罪人，一直不敢说。
2. 时菱发现许知言原本在预排名单中，周妍是后来补进去的人。
3. 周妍是最大受益者，但不是直接凶手。她知道自己保送有问题，也知道许知言发现了异常。
4. 许母补充，许知言曾提过“杜老师”找过她。

### 第三阶段：杜明川露馅

1. 杜明川表面镇定，承认自己负责保送工作，却试图把一切解释成正常流程。
2. 时菱从他的心声和反应中捕捉到“天台”。
3. 杜明川在警方未提及天台的情况下主动说出，暴露自己知道关键地点。
4. 时菱建议立刻封锁实验楼天台并复查许知言衣物。

### 第四阶段：物证落地

1. 技术人员在许知言校服外套后背靠右肩胛位置发现重掌缘压痕。
2. 后领塑封校牌边缘提取到三枚清晰指纹，经比对属于杜明川。
3. 天台东侧铁网口找到与杜明川当晚深色衬衫对应的扣子。
4. 杜明川承认自己收钱、篡改保送名单，并在天台和许知言争执抢证据。

## 证据链

1. 保送预排名单与最终名单变化，证明许知言被顶替。
2. 周妍后补材料和周妍家现金行贿，证明利益链。
3. 杜明川主动说出“天台”，证明他知道案发关键地点。
4. 校服后背掌缘压痕、后领校牌指纹、天台扣子，证明杜明川从背后对许知言动过手。
5. 杜明川口供与物证相互印证。

## 时菱发挥点

- 不接受“学习压力自杀”的单一解释，从保送变动和许母求助切入。
- 通过梁芳、周妍、杜明川三层反应，逐步确认保送黑幕。
- 抓住杜明川“天台”露馅，推动警方封锁关键现场并重新提取物证。

## 人物变化

- **时菱**：第一次面对“人已经救不回来”的案件，意识到追凶本身也有意义。
- **陈继东**：开导时菱，帮她建立对刑侦工作的长期认知。
- **顾晏廷**：在许母感谢时菱的场景中进入主线视野。
- **许母**：从绝望求助到等来真相，是本案主要情绪落点。

## 后续可回收点

1. 许知言案可作为教育公平议题的回声。
2. 许母感谢时菱，是顾晏廷初见时菱的重要现场背景。
3. 本案让时菱明白，并不是所有受害者都能及时救回，但真相仍然有价值。
